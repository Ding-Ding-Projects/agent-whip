Crack a whip at your coding agent.

agent-whip switches a running AI coding agent session into a faster operating mode by delivering a short trigger phrase into it — never by interrupting it. A mode switch, not a nag.

Download v0.1.0 for Windows View the release
Unsigned installer. agent-whip does not use code signing, on principle — see Privacy. Windows SmartScreen will warn about an unrecognized publisher before you can run it. That warning is expected, not a sign anything is wrong.

Why this is not an interrupt

agent-whip's ancestor is OpenWhip — a tray app you click, which drops a whip overlay and sends Ctrl-C plus one of five encouraging messages. It's a joke, and a good one. We mean the credit warmly: agent-whip exists because the bit was too good not to build properly.

But an interrupt-based whip has a real problem hiding under the joke: it makes the agent slower. Ctrl-C discards whatever the agent was mid-turn on, so the "motivational" message that follows starts a brand new turn from scratch rather than resuming anything. Every crack costs the agent its entire in-flight response.

agent-whip inverts the payload. A crack injects a short trigger phrase into the live session, timed and framed so the agent reads it as ordinary input — not a signal to abandon its current turn. No discarded turn, no interrupt signal, no work thrown away.

Two tiers, no confirmation prompt

Single crack — tier 1

One trigger. Switches the session to a faster operating mode.

Double crack — tier 2

Two triggers within roughly two seconds. Speed mode, plus cleanup authorization.

Read why there is deliberately no yes/no dialog on either tier in Crack tiers — the short version: agent-whip's job ends at delivering text, so it has no way to judge whether an action is safe. That judgment belongs to the receiving agent, not to a decoration in this tool.

Nothing leaves the machine

No network access, no telemetry, and no real trigger phrases anywhere in this repository or on this site. Payload text is never displayed — only its hash and length, like sha256:26e9f54e24fa (22 chars). Full detail in Privacy.
